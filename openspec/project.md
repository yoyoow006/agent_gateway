# 项目上下文

当前项目使用风险分级 AI 编程工作流。助手入口位于根目录，共享知识和规则位于 `.ai/`，标准与严格变更状态位于 `openspec/`。

- 快速模式不创建 OpenSpec 数据。
- 标准模式使用四件套和单次实施前确认。
- 严格模式增加独立计划、第二次实施前确认和完整审查门禁。
- proposal 的模式、状态以及 tasks 勾选是跨会话恢复真源。

安装资产不预设目标项目的业务模块、构建系统或部署拓扑。维护者应从目标代码、主规格和权威文档核对后更新共享知识。

保护用户修改；外部或破坏性动作需要明确授权；范围扩大时重新确认；完成声明前运行与风险相称的验证。
